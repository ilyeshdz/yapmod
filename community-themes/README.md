# Community themes

Each published theme lives in its own folder here. To submit a theme, add a
folder whose name matches the theme `id`, then open a pull request.

The folder must contain `manifest.json` and the stylesheet named in its `css`
field. Community themes are CSS only; keep stylesheets under 1 MB.

The website build validates these folders and publishes a static catalog and
the theme files. Do not edit the generated catalog by hand.

See the [Submit a theme guide](https://ilyeshdz.github.io/yapmod/docs/submit-a-theme/)
for the full pull request and validation steps.
