# Community themes

Each published theme lives in its own folder here. To submit a theme, add a
folder whose name matches the theme `id`, then open a pull request.

The folder must contain `manifest.json`, the stylesheet named in its `css`
field, and a preview image named in its `preview` field. Community themes need
a preview so people can browse them in the app before installing. Use PNG,
JPEG, WebP, GIF or SVG for previews, keep them under 4 MB, and keep stylesheets
under 1 MB.

The website build validates these folders and publishes a static catalog and
the theme files. Do not edit the generated catalog by hand.
