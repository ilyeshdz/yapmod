## Browse and install

Open **Settings → Themes** to browse community and local themes in one gallery. Search by theme name, author, description or tag, then turn on the switch on a theme's card. Yapmod installs it in the background and applies it right away.

The app reads a static catalog from the Yapmod website. It does not need an account, and theme files are only downloaded when you choose to install one. Community themes use the same format as [local themes](/yapmod/docs/themes).

Themes are community-made CSS and can change or break the interface. Review the author and license shown with a theme. Turning its switch off returns to Yapper's theme and keeps the theme installed, so you can turn it back on instantly.

Want to publish your own? Follow [Submit a theme](/yapmod/docs/submit-a-theme).

Themes contain CSS, not JavaScript. CSS can still affect the interface and request remote assets, so only install themes you trust.
