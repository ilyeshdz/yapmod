yapmod is a free, open-source desktop app for [Yapin](https://www.yapin.gg). It uses the Yapin web app, so you sign in with the same account and keep the same servers, channels and messages.

yapmod is an independent community project. It is not made by, endorsed by or affiliated with Yapin.

## What is different from using Yapin in a browser?

It has its own window and keeps desktop-specific settings in Yapin's settings, such as notifications, the unread badge, keeping the app in the menu bar or system tray, and theme selection.

External links open in your default browser. A theme can change the Yapin interface, the yapmod settings and dialogs.
